SHOW keys

Hands on the keys.

Every function of the app is an action. An action has a name, a place in the menu, an entry in the command palette (Cmd/Ctrl+Shift+P) and a shortcut you can change.

DEFAULT shortcuts per system

The defaults.

Two strokes in a row are a chord: ⌘K ⌘X means press one, then the other. Change any of them in the shortcut editor, Cmd/Ctrl+K Cmd/Ctrl+S. The keys of the editor itself (copy, paste, undo, find) stay with the editor.

WITH focus

Where a key acts.

A shortcut never surprises you in the wrong place: plain keys do not reach an action while you type, and the grid has keys of its own.

editor

In the SQL editor

Copy, cut, paste, select all, undo, find (Cmd/Ctrl+F, F3) and completion (Ctrl+Space) belong to the editor. Plain keys and AltGr characters are always text.

grid

In a result

Arrows, Shift + arrows for a range, Cmd/Ctrl+F searches the result (not the editor), F2 edits a cell, F4 follows a foreign key.

tree · menu · dialog

In lists, menus, dialogs

Trees, menus, list boxes and splitters follow the ARIA authoring practices: arrows, Home, End, type to find, Esc closes.

EXPLAIN questions

Asked before.

Where are my passwords?

In the keychain of your system (Keychain on macOS, Credential Manager on Windows, the Secret Service on Linux), or nowhere: a connection can ask each time. The file with the connection profiles never holds a secret, and neither does an export of them.

Does the app send anything anywhere?

No. There is no account, no telemetry and no update check. The app talks to the databases you connect it to, and to an SSH server if you set up a tunnel. The AI control is off until you switch it on, and then it listens on this computer only.

What happens to my text when the app crashes?

Every tab is backed up a moment after you type. After a restart or a crash the tabs are there again, with their text, their connection and the caret. That is why nothing asks “save?”. A tab that is a .sql file is saved to it with Cmd/Ctrl+S and keeps its encoding.

Can I break production by accident?

Less easily. Give the connection a protection level: “ask” puts a question before everything that is not reading, “read only” runs nothing else. The statement is classified in the backend, not by the window. Editing data, importing, copying tables and changing structure all go through the same check.

How large may a result be?

Results are kept by the backend, first in memory and above a limit in a file, with limits you can set. The grid asks for the rows on screen. Sorting, filtering, searching and the figures of a selection work on the stored result without running the statement again.

Why does macOS or Windows warn me when I open the app?

The packages are not signed yet, so the system does not know the publisher. On macOS, open the app once with a right click and “Open”. On Windows, choose “More info” and “Run anyway”. The source of every release is the tag on GitHub; the packages are built there by a public workflow.

What is it built with?

Tauri 2 with a Rust backend and an Angular window. The SQL editor is editlicious, the grids are the GuiExpert Table. Every package carries the licences of what is inside; Help → About shows them.
