# Design 035h: Cloudflare D1

> Durchlauf von [Prompt 035](035-weitere-datenbanken.md) für **Cloudflare D1**. Stand: umgesetzt am 12.11.2026
> (ohne Freigabe-Halt, Marcs Anweisung vom 11.11.2026) – **nach Cloudflares Dokumentation geschrieben, nicht gegen
> Cloudflare gelaufen**: Dafür braucht es ein Konto. Die Tests sprechen mit einem eigenen Server, der antwortet, wie
> die Dokumentation es beschreibt.

## Ergebnis in einem Satz

D1 ist eine eigene `DbKind` mit dem Dialekt von SQLite zum **Lesen und Ausführen**: verbinden, Anweisungen
ausführen (auch schreibende), Baum, Details, Tabellen-Ansicht mit Filter, Suche. Zeilen im Gitter ändern, Import,
Kopieren und Struktur bearbeiten gibt es dort nicht: Über die API lebt keine Transaktion länger als eine Anfrage.

## Entscheidungen

| # | Entscheidung | Warum |
|---|---|---|
| E1 | **REST-API von Cloudflare** (`POST …/accounts/{konto}/d1/database/{id}/raw`) mit `ureq` | der einzige Weg von außen; D1 hat kein Datenbankprotokoll. `/raw` gibt Zeilen als Listen mit den Spaltennamen daneben (bei `/query` gingen gleichnamige Spalten verloren) |
| E2 | Das Profil: **Benutzer = Account-ID**, **Datenbank = ID der Datenbank**, **Passwort = API-Token** (Schlüsselbund), Host `api.cloudflare.com`, TLS geprüft. Beide IDs werden Teil der Adresse und sind darum nur Buchstaben, Ziffern, Bindestriche – oder gar nichts | kein neues Feld im Profil; das Fenster nennt die Felder beim Namen |
| E3 | Das Token geht nur über TLS (oder an diesen Rechner, für Tests); auch nicht ohne TLS durch einen Tunnel | es öffnet das ganze Konto |
| E4 | Werte reisen als `params` – **als Text**, wie die Dokumentation sie beschreibt | SQLite liest einen Text als das, was die Spalte ist, mit der er verglichen wird. Wo keine Spalte gegenübersteht (`WHERE 1 = ?`), bleibt er Text |
| E5 | Ein Text aus mehreren Anweisungen läuft auf dem Server als ein Stapel; die Antwort ist die der **letzten** | so sagt es die API |
| E6 | **Keine Sitzung, keine Transaktionen**: `transaction_state` ist immer „keine“; `edits_rows` ist falsch, die Flags `edit` und `structure` sind aus, der manuelle Modus des Tabs wird abgelehnt | was eine Transaktion braucht, um sicher zu sein, wird nicht versprochen (wie bei ClickHouse) |
| E7 | **Kein Abbruch**: Eine Anfrage läuft auf einem eigenen Thread; gestoppt oder über der Zeit wird sie zurückgelassen | die API hat nichts dafür |
| E8 | Spaltenart aus dem **ersten Wert**, der nicht NULL ist | die Antwort nennt keine deklarierten Typen |
| E9 | **Nur lesen** entscheidet das Token bei Cloudflare (Recht „D1 Read“); die App stuft ein wie überall. Ein Assistent bekommt auf D1 keine Abfrage ausgeführt | es gibt keine Sitzung, die nur lesen dürfte, und keine Transaktion zum Zurückrollen |
| E10 | D1s eigene Tabellen (`_cf_…`) zeigt der Baum nicht | niemand darf sie lesen |

## Grenzen, die von der API kommen

- Ganze Zahlen jenseits von 2^53 kommen gerundet an (JSON), BLOBs als Liste ihrer Bytes.
- Das Ergebnis kommt als Ganzes, nicht als Strom; eine Anweisung darf 100 KB lang sein.
- Die Stelle eines Fehlers steht nur dort, wo Cloudflare sie nennt (`at offset N`).

## Nicht getestet

- **Alles gegen Cloudflare**: die Form der Antworten und Fehler, ob `params` Zahlen annähme, ob die
  Katalogabfragen der App (`pragma_table_list`, `pragma_table_info(…)`, `pragma_foreign_key_list(…)`,
  `sqlite_master`) dort so laufen wie in SQLite. Der erste Lauf gegen ein echtes Konto ist der eigentliche Test.
- Das native Fenster.

## Tests

- `src-tauri/src/db/d1_tests.rs` (5 Tests, bei jedem `cargo test`): was gesendet wird (Adresse, Token, Text und
  Werte getrennt), wie Antworten gelesen werden (Typen, NULL, BLOB, geänderte Zeilen, mehrere Anweisungen), Fehler
  (falsches Token ohne es zu nennen, Syntax mit Stelle, verbotene Tabelle, 429, HTML eines Gateways, `success:
  false` in einer 200), Profile, die etwas verraten oder umleiten würden, Stopp und Zeitlimit.
- `mod.rs` (Flags), im Fenster `connection-logic.spec.ts` (Felder, Host, Dialekt).

## Review

Ein zweiter, nur lesender Blick, gegen Cloudflares Dokumentation und – wo sie schweigt – gegen den offenen Quelltext
von `workerd` gelesen, auf dem D1 läuft (dort steht, welche Funktionen und PRAGMAs erlaubt sind). Behoben, mit Tests
in `d1_tests.rs`:

| # | Befund | Behebung |
|---|---|---|
| 1 (hoch) | Die Probe beim Verbinden fragte `sqlite_version()` – das lässt D1 vermutlich niemanden fragen: Keine Verbindung wäre je aufgegangen | Probe ist `SELECT 1`; die Version heißt schlicht „Cloudflare D1“ |
| 2 (hoch) | Schema-Baum und Namensindex fragten `pragma_database_list` – in D1 nicht erlaubt | für D1 ist das Schema fest `main`, ohne zu fragen |
| 3 (hoch) | Durch einen SSH-Tunnel wäre das Token ohne TLS weitergegangen | D1 kennt keinen Tunnel (Profilprüfung und Verbindungsaufbau) |
| 4 | Ungeprüftes TLS und ein beliebiger Host wurden für das Token angenommen | nur `api.cloudflare.com` mit geprüftem Zertifikat (oder dieser Rechner, für Tests) |
| 6 | Cloudflare nimmt 100 Werte je Anweisung, die App bis 2000 | ab 101 sagt der Treiber es in Worten, bevor er sendet |
| 7 | Eine Anfrage hatte kein Zeitlimit: zurückgelassene Threads konnten ewig leben | 45 s je Anfrage (Cloudflare beendet nach 30 s) |
| 8, 10 | Antwort bis 256 MB angenommen, Anweisung bis 102 400 Bytes | 64 MB (Cloudflare: 50 MB), 100 000 Bytes |
| 9 | Spaltenart nur aus dem ersten Wert: `2` vor `1.5` machte eine Ganzzahl-Spalte; eine Zeile falscher Länge wurde verworfen | Art über alle Werte; die Zeile ist ein Fehler |
| 11 | Die Tests behaupteten, was der echte Dienst nicht täte (Version, `2.0`, eine Zahl über 2^53, eine Stelle um eins daneben) | berichtigt |
| – | `struct_apply` hätte bei D1 erst an `BEGIN` gemerkt, dass es nicht geht | `structure::plan` lehnt D1 ab |

Offen geblieben:

- **Werte als Text** (E4): Wo kein Spaltentyp gegenübersteht (`WHERE menge * 2 > :n`, typlose Spalten), vergleicht
  SQLite Text mit Zahl – ohne Fehler, mit falschen Zeilen. Ob die API JSON-Zahlen annähme, entscheidet ein Lauf gegen
  ein echtes Konto; dann gehören Zahlen als Zahlen gesendet.
- Ganze Zahlen über 2^53 kommen gerundet an und sehen genau aus.
- Die Antwort wird als Ganzes gelesen, nicht als Strom.
- Ein gestoppter `UPDATE` läuft bei Cloudflare zu Ende – der Stopp sagt das nicht eigens (ein Stopp ist für den
  Nutzer keine Fehlermeldung).
- Ob `EXPLAIN QUERY PLAN` über die API geht und wie Fehler dort wirklich aussehen, ist unbelegt.
